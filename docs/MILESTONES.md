# Vok (Linux) 里程碑规划 (Milestones & Roadmap)

> 遵循 Vok 架构铁律：**分阶段交付纵向切片，前置里程碑必须通过真实物理环境与自动化门禁验收，严禁以假实现或跳过门禁进入下一阶段。**

---

## 里程碑概览

| 阶段 | 代号 | 核心交付目标 | 验收门槛与核心指标 | 状态 |
| :--- | :--- | :--- | :--- | :--- |
| **M0** | **宿主与拖动呼出入站内核** | 物理键态状态机 + 全屏 Overlay 浮层 + 外部拖拽中呼出入站 | 真实键盘长短按无抖动，外部拖动中呼出瞬时捕获 `text/uri-list`，常驻内存 < 30MB | **当前启动** |
| **M1** | **中转站引用型货架 MVP** | SQLite WAL 持久化 + GTK4 自适应卡片流 + 异步缩略图 Worker | 零拷贝秒级入库，200 条目渲染无掉帧，原文件 100% 零修改 | 待开始 |
| **M2** | **出站拖放与全量消费闭环** | 透明代理锚点外部拖出 + 键盘一键消费交还 + DBus 目录定位 | 拖出外部成功落地且无 Wayland 中断崩溃，Enter 快捷消费直达目标窗口 | 待开始 |
| **M3** | **剪贴板历史与统一增强检索** | 剪贴板后台监听 + `/dev/uinput` 硬件直接粘贴 + 拼音统一搜索 | 复制去重无回流，直接粘贴支持终端与桌面应用，搜索响应 < 20ms | 规划中 |
| **M4** | **生产级打包与体验打磨** | 托盘集成 + 权限诊断引导 + 跨桌面（GNOME/KDE/Hyprland）自适应 | 提供标准 `.desktop`、systemd 用户服务与 udev 规则，开箱即用 | 规划中 |

## 阶段详情与验收门禁

### M0：宿主与拖动呼出入站内核 (Host Kernel & Mid-drag Drop-in)

* **目标**：不实现复杂 UI，专注于闭环最底层的核心系统契约。
* **交付范围**：
  1. **`vok-infra::input`**：
     - 基于 Linux 内核 `/dev/input/event*`（`evdev`）建立常驻输入线程；
     - 实现硬件微秒级时间戳的按键电平状态机；
     - 准确分离 `Momentary`（长按 > 250ms）与 `Toggle`（短按 ≤ 250ms）信号；
     - 建立带代次令牌的 `HotkeyEvent(GenerationId, KeyState)` 派发机制。
  2. **`vok-app::window`**：
     - 在 Wayland 下通过 `gtk4-layer-shell` 建立 `OVERLAY` 层级全屏透明遮罩；
     - 在 X11 下通过标准 EWMH DOCK/ABOVE 属性建立无边框置顶遮罩；
     - 实现全屏面板的瞬时创建、原子映射（Map）与取消（Unmap）。
  3. **拖动呼出入站协议 (Mid-drag Drop-in)**：
     - 在全屏面板挂载 `GtkDropTarget`，接收 `text/uri-list`；
     - 验证核心场景：**在外部应用（Nautilus / Dolphin）中按住鼠标左键抓取文件 -> 在半空中按下配置的快捷键 -> 全屏面板瞬间揭示 -> 鼠标移入并释放 -> 成功拿到路径列表 -> 松开快捷键面板立即隐藏**。
* **验收门禁 (M0 Gate)**：
  - [ ] 真实物理键盘按下到全屏浮层呈现延迟 < 16ms（1帧内）；
  - [ ] 外部拖拽中呼出，文件释放成功率 100%，无事件丢失或死锁；
  - [ ] 进程常驻后台空闲内存严格 < 30MB。

---

### M1：中转站引用型货架 MVP (Stage Shelf & UI Cards)

* **目标**：实现高颜值、高流动性、自适应的纯引用型文件卡片货架。
* **交付范围**：
  1. **`vok-infra::storage`**：
     - 初始化 `$XDG_DATA_HOME/vok/vok.db`（SQLite WAL 模式）；
     - 设计 `stage_items` 表，实现单写者安全事务管道与启动恢复加载；
     - 强一致性校验：每次呼出自动轻量检查原文件物理存在性，标记失效文件。
  2. **`vok-infra::assets`**：
     - 独立后台线程 Worker，为拖入的图片与文档提取/生成 160px PNG 缩略图；
     - 缩略图落盘至 `$XDG_CACHE_HOME/vok/thumbs/`，设 50MB 有界回收配额。
  3. **`vok-app::stage`**：
     - GTK4 自适应卡片列表，支持图标、文件名、尺寸格式化、时间展示；
     - 支持卡片 Hover 态、Pin（锁定）与单项 Delete 操作；
     - 支持一键清空（仅清空引用，原文件毫发无损）。
* **验收门禁 (M1 Gate)**：
  - [ ] 单次拖入 50 个大文件，UI 线程完全不卡顿，1 秒内完成入库与视图更新；
  - [ ] 连续增删 200 项，SQLite 数据库无损坏，WAL 文件自动截断；
  - [ ] 严格证明对原文件无写操作。

---

### M2：出站拖放与全量消费闭环 (Drag-Out & Consumption Pipeline)

* **目标**：让暂存在中转站里的文件能够顺畅地流向系统各处。
* **交付范围**：
  1. **透明代理锚点拖出 (Drag-Out)**：
     - 为卡片挂载 `GtkDragSource`，内容提供 `GdkFileList` / `text/uri-list`；
     - 拖动起手瞬间将主面板置为全透明代理，保持 Wayland Source Surface 存活；
     - 支持将文件拖入外部编辑器、聊天工具或目标文件夹。
  2. **键盘极客直通消费**：
     - 键盘焦点导航：方向键导航选中卡片；
     - `Enter` / `Space`：将选中文件路径写入系统剪贴板，立即隐藏工作台并把前台焦点交还给呼出前的应用；
     - `Delete`：移除选中项。
  3. **系统联动**：
     - `Ctrl + Enter`：通过 DBus `org.freedesktop.FileManager1.ShowItems` 直接在系统文件管理器中打开并高亮选中文件。
* **验收门禁 (M2 Gate)**：
  - [ ] 在 Wayland (Hyprland/Sway/GNOME) 下拖出至外部应用 100% 成功，无会话被中断假死现象；
  - [ ] 快捷消费后焦点顺利返回终端/编辑器，可立即进行下一步操作。

---

### M3：剪贴板历史与统一增强检索 (Clipboard & Search Integration)

* **目标**：在全屏面板中横向扩展剪贴板历史与全盘文件统一搜索能力。
* **交付范围**：
  1. **剪贴板子系统**：
     - 监听系统剪贴板（文本、PNG 图片 aHash 去重、`text/uri-list` 文件）；
     - 支持无感直接粘贴（通过 `/dev/uinput` 注入 Ctrl+V / Shift+Insert）。
  2. **统一聚合搜索 (Ctrl+K)**：
     - 统一输入框，混合检索：本地应用（.desktop）、中转站条目、剪贴板历史；
     - 采用 Rust 纯内存前缀与拼音（全拼/简拼）匹配内核；
     - 联动系统 `plocate` 引擎，支持全盘文件秒搜。
* **验收门禁 (M3 Gate)**：
  - [ ] 剪贴板自写过滤可靠，不发生死循环入库；
  - [ ] 搜索框输入到首批结果渲染响应 < 20ms。

---

### M4：生产级打包与体验打磨 (Packaging & Polish)

* **目标**：达到长期稳定日用标准。
* **交付范围**：
  1. 系统托盘图标（StatusNotifierItem 规范，支持右键唤出/退出）；
  2. 权限与环境引导器（自动检测当前用户是否属于 `input` 组，提供免配置或 udev 规则引导）；
  3. 提供针对 Arch (AUR)、Fedora/Ubuntu 的打包脚本与 systemd 用户服务配置。
* **验收门禁 (M4 Gate)**：
  - [ ] 连续常驻运行 72 小时无内存泄漏，无僵死线程；
  - [ ] 跨不同 DPI 缩放显示器切换无布局撕裂。
