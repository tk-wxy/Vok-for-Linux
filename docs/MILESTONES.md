## 阶段详情与验收门禁

### M0：宿主与拖动呼出入站内核 (Host Kernel & Mid-drag Drop-in)

* **目标**：专注于闭环最底层的核心系统契约，打通物理按键、任务栏避让与拖拽呼出落入。
* **交付范围**：
  1. **`vok-infra::input`**：
     - 基于 Linux 内核 `/dev/input/event*`（`evdev`）建立常驻输入线程；
     - 实现硬件微秒级时间戳的按键电平状态机；
     - 准确分离 `Momentary`（长按 > 250ms，松手即隐）与 `Toggle`（短按 ≤ 250ms，保持显隐切换）信号；
     - 建立带代次令牌的 `HotkeyEvent(GenerationId, KeyState)` 派发机制。
  2. **`vok-app::window`**：
     - 在 Wayland 下通过 `gtk4-layer-shell` 建立 `OVERLAY` 层级全屏透明遮罩，并安全避让系统任务栏（保留任务栏可见性）；
     - 在 X11 下通过标准 EWMH DOCK/ABOVE 属性与 `_NET_WORKAREA` 建立工作区遮罩；
     - 建立焦点上下文暂存：呼出时暂存原活动窗口句柄，面板入焦并默认聚焦顶部搜索框；
     - 实现全屏面板的瞬时创建、原子映射（Map）与取消（Unmap）。
  3. **拖动呼出入站协议 (Mid-drag Drop-in)**：
     - 在全屏面板挂载 `GtkDropTarget`，接收 `text/uri-list`；
     - 验证核心场景：**在外部应用（Nautilus / Dolphin）中按住鼠标左键抓取文件 -> 在半空中按下配置的快捷键 -> 全屏面板瞬间揭示 -> 鼠标移入中转区并释放 -> 成功拿到路径列表 -> 松开快捷键面板立即隐藏**。
* **验收门禁 (M0 Gate)**：
  - [ ] 真实物理键盘按下到全屏浮层呈现延迟 < 16ms（1帧内）；
  - [ ] 外部拖拽中呼出，文件释放成功率 100%，无事件丢失或死锁；
  - [ ] 进程常驻后台空闲内存严格 < 30MB。

### M1：三栏骨架与双货架 MVP (Three-Pane Layout, Launcher & Stage Shelf)

* **目标**：落地主界面 1:2:1 横向布局，完成启动台与中转站两大核心货架，奠定防截断高度算法与虚拟化视口基础。
* **交付范围**：
  1. **主界面 1:2:1 骨架与高度算法**：
     - 按照横向 1:2:1 划分【启动台 (25%)】、【中转站 (50%)】、【剪贴板占位 (25%)】；
     - 实现卡片高度动态整除算法：根据当前可用高度动态计算卡片高度，确保启动台与中转站底部最后一行卡片 100% 完整显示，规避 UI 截断；
     - 顶部常驻全局搜索框与右上角设置齿轮按钮。
  2. **`vok-infra::storage`**：
     - 初始化 `$XDG_DATA_HOME/vok/vok.db`（SQLite WAL 模式），包含 `launcher_items` 与 `stage_items` 表；
     - 单写者事务通道，支持卡片顺序 `order_index` 变更批量事务。
  3. **启动台 (Launcher)**：
     - 一行 4 个项；
     - 左键单击：启动目标应用/文件，**同时自动隐藏面板**；
     - 右键菜单：【启动】、【打开所在目录】（DBus FileManager1）、【移除该项】；
     - 拖动排序：卡片长按拖拽重新排位并即时持久化；
     - 外部拖入添加：外部拖拽应用/文件 -> 呼出面板 -> 在启动台松手 -> 解析并新增启动项。
  4. **中转站 (Stage)**：
     - GTK4 `GtkGridView` 原生视口回收，支持图标、文件名、尺寸、时间；
     - 外部拖入秒级入库，后台 Worker 异步提取 160px PNG 缩略图（50MB 缓存上限）；
     - 右键菜单：【打开】、【粘贴】、【复制到剪贴板】、【打开所在目录】、【删除】；
     - 拖动排序：卡片拖拽调整前后顺序。
* **验收门禁 (M1 Gate)**：
  - [ ] 启动台与中转站底部卡片完美完整展示，无任何半截截断现象；
  - [ ] 单次拖入 50 个大文件，UI 线程完全不卡顿，1 秒内完成入库与视图更新；
  - [ ] 连续增删 200 项，SQLite 数据库无损坏，WAL 文件自动截断；
  - [ ] 严格证明对用户原文件无写操作。

### M2：焦点精准返还与双向消费闭环 (Focus Restoration, Direct Paste & Drag-Out)

* **目标**：实现原前台焦点精准返还、失焦自动关闭、基于 `/dev/uinput` 的直接粘贴以及透明代理拖出外部。
* **交付范围**：
  1. **焦点生命周期与精准返还**：
     - 面板关闭时，原子将前台焦点精确归还给呼出前的原始活动窗口与控件（如浏览器搜索框、IDE 文本框）；
     - 支持 Esc 键关闭、快捷键再按一次（Toggle）关闭；
     - **失焦自动关闭 (Focus-Out)**：用户鼠标点击任务栏或其他非面板区域，面板自动平滑关闭。
  2. **硬件级直接粘贴 (Direct Paste)**：
     - 中转站卡片左键单击：将文件路径写入剪贴板 -> 隐藏面板 -> 返还焦点 -> 通过 `/dev/uinput` 注入按键（Ctrl+V），直接粘贴到目标应用光标处。
  3. **透明代理锚点拖出 (Drag-Out)**：
     - 为中转站卡片挂载 `GtkDragSource`；
     - 拖动起手瞬间面板置为全透明存活代理，保持 Wayland Source Surface 不中断；
     - 外部目标（文件管理器、桌面、编辑器）释放后收到文件，收到 `drag-end` 信号后完成隐藏。
* **验收门禁 (M2 Gate)**：
  - [x] 在 Wayland (Hyprland/Sway/GNOME) 与 X11 下拖出至外部应用 100% 成功，通过 vok-proxy-anchor 彻底规避会话中断缺陷；
  - [x] 左键单击中转项后，文件路径 100% 自动粘贴进原前台文本框/终端，R7 延时时序守卫杜绝自身吸收；
  - [x] 点击任务栏或外部应用，面板无缝关闭且底层窗口无任何异常响应，原前台焦点 100% 原子返还。

### M3：剪贴板历史与统一增强检索 (Clipboard & Unified Search)

* **目标**：补齐右侧剪贴板历史区，实现顶部全局搜索框的三区联动过滤，并预留全盘增强搜索架构。
* **交付范围**：
  1. **剪贴板历史子系统**：
     - 监听系统剪贴板（文本、PNG 图片 aHash 去重、`text/uri-list` 文件列表）；
     - 采用 `GtkListView` 虚拟列表渲染；
     - 左键单击：直接粘贴到原焦点处；提供复制到剪贴板、删除等操作；
     - 外置资产管理：剪贴板大图独立存储在 `$XDG_DATA_HOME/vok/assets/`。
  2. **顶部全局统一联动搜索框**：
     - 顶部统一搜索框输入关键词，同时实时过滤【启动台】、【中转站】与【剪贴板】；
     - 内存索引检索响应 < 20ms。
  3. **增强搜索视图架构预留 (Enhanced Search)**：
     - 依附于主界面的视图栈；
     - 预留通过特定快捷键平滑切换“三栏工作台”与“全盘增强搜索”界面。
* **验收门禁 (M3 Gate)**：
  - [ ] 剪贴板自写过滤可靠，不发生死循环入库；
  - [ ] 累积 2,000 条剪贴板历史，列表滚动无掉帧，常驻内存依然 < 40MB；
  - [ ] 搜索框输入到首批三区过滤结果渲染响应 < 20ms。

### M4：独立设置与生产级打磨 (Settings Dialog, Packaging & Polish)

* **目标**：实现独立设置小窗口、系统托盘常驻，完成跨桌面自适应与生产级打包。
* **交付范围**：
  1. **独立设置小窗口 (Settings Dialog)**：
     - 独立 GTK 窗口，由托盘右键菜单项或主界面右上角齿轮图标打开；
     - 支持主题切换（浅色/深色/跟随系统）、快捷键自定义修改、开机自启等。
  2. **系统托盘集成**：
     - 支持 StatusNotifierItem (SNI) 规范；
     - 托盘右键菜单包含：【呼出工作台】、【设置】、【退出】。
  3. **权限引导与生产打包**：
     - 自动检测当前用户是否属于 `input` 组，提供友好的免配置/udev 引导；
     - 提供标准 `.desktop` 文件、systemd 用户服务与 Arch/Fedora/Ubuntu 打包配置。
* **验收门禁 (M4 Gate)**：
  - [ ] 连续常驻运行 72 小时无内存泄漏，无僵死线程；
  - [ ] 跨不同 DPI 缩放显示器切换无布局撕裂与卡片重叠。
